title: Open tasks from Slack and post questions back
description: Add the Slack module so a mention of your Slack app opens a task, and the task's questions are posted back to Slack.
---

The tasks open on the team's delivery line, and a reply in a question's Slack
thread answers it. You need:

- A Slack app you can configure, installed in your Slack workspace.
- Terraform 1.11 or later, set up with the Spotlight provider, using a token
  that has the `configure` and `secrets` scopes. See
  [Manage Spotlight with Terraform](/docs/configuration/manage-spotlight-with-terraform).
- A team with a line whose role is `delivery` and a station keyed `triage`,
  as the built-in Delivery line has.
- A Spotlight deployment that allows outbound calls to `slack.com`, since
  Spotlight calls Slack's API from its own servers.

## Prepare the Slack app

In the Slack app's settings:

<Steps>
<Step>

Give the app's bot the scopes `app_mentions:read`, `chat:write`,
`channels:history` and `reactions:write`, and reinstall the app.

</Step>
<Step>

Copy the app's bot token and its signing secret.

</Step>
<Step>

Note the ID of the Slack channel that questions from other tasks should go
to.

</Step>
</Steps>

## Add the Slack module

The [Slack module](https://registry.terraform.io/modules/usespotlightai/slack/spotlight)
keeps the signing secret and the bot token as workspace secrets, and creates
the Slack integration on the team. A task opened from Slack posts its
questions to the channel it was opened from. `routes` names the channel for
questions from a line's other tasks, by the line's key (`delivery` is the
built-in Delivery line's key): replace `<channel id>` with the channel you
noted.

```hcl
variable "slack_signing_secret" {
  type      = string
  sensitive = true
  ephemeral = true
}

variable "slack_bot_token" {
  type      = string
  sensitive = true
  ephemeral = true
}

module "slack" {
  source  = "usespotlightai/slack/spotlight"
  version = "~> 0.1"

  workspace = "acme"
  team      = "core"

  signing_secret = var.slack_signing_secret
  bot_token      = var.slack_bot_token

  routes = {
    delivery = "<channel id>"
  }
}

output "slack_webhook_url" {
  value = module.slack.webhook_url
}
```

Change `workspace` to the part after `/w/` in the workspace's address, and
`team` to your team's key. If new tasks should open on another line or at
another station, set `line_role` and `station`. To react with another emoji,
set `acknowledge` to its name, or to `null` for no reaction. On a
[self-hosted Spotlight](/docs/reference/glossary#spotlight-address), set
`spotlight_url` to your deployment's address. Run `terraform apply`.

## Point Slack at the team

In the Slack app's event subscription settings:

<Steps>
<Step>

Turn events on and give the `slack_webhook_url` output as the request URL.
Slack sends a challenge, Spotlight responds to it, and Slack marks the
address verified.

</Step>
<Step>

Subscribe the bot to the `app_mention` and `message.channels` events.

</Step>
<Step>

Save, and reinstall the app if Slack asks.

</Step>
</Steps>

## Check it

Mention the app in a channel it has joined. A task opens at **Triage** on the
delivery line, titled with the message, and the app reacts to the mention
with the `eyes` emoji. When the task asks a question, the question appears in
the channel, and a reply in its thread answers it and resumes the work.
