title: Add a task and move it along a line

Tasks are added and moved on a line's board. To open it, go to **Your teams**
in the sidebar, expand the team, and select the line under **Lines**. The pills
above the board switch between **Backlog**, **Active** (the stations where
agents work) and **Completed**.

## Decide where the task starts

Where you add a task decides whether work begins at once:

- At the backlog, the task waits. Nothing runs until you move it on. Use this
  for work you want to write down now and start later, or to add several tasks
  before any of them runs.
- At a work station whose agent has a harness, a run starts as soon as the task
  is created. Every work station of the built-in lines has one.

A task you create is assigned to you, so its questions and failures come to
your inbox.

## Add the task

<Steps>
<Step>

Select **Backlog** or **Active**, then select **+** at the right of the
station's header.

</Step>
<Step>

Write the title in **Task title**, and what you want done in
**Add description…**, which takes Markdown. Write both in full: neither can be
edited once the task exists.

</Step>
<Step>

To give the agent files, select the paperclip, or drop or paste files onto the
dialog. Each file can be up to 25 MiB. The agent finds them in its workspace.

</Step>
<Step>

Select **Create task**. It stays disabled until the title is filled in and
every file has finished uploading.

</Step>
</Steps>

The task appears at the bottom of the station. To add several in a row, turn
on **Create more** before you select **Create task**; the dialog then clears
and stays open for the next one.

## Assign it to someone else

On the board, select the avatar near the right end of the task's row, before
the date. On the task page, use the control under **Properties** that reads
**Assign this task** or `Assigned to <name>`. Pick a person from the team, or
**No assignee**.

The assignee is the person whose inbox the task reaches, and the only person
who can talk to its runs or stop them.

## Move the task

Start a task by moving it from the backlog to a work station, park it by
moving it back to the backlog, or close it by moving it to **Completed**. A
move to a work station with a harness starts a run there; parking stops work
on the task without starting another run. To have another station redo work,
[send it back through the run's
chat](/docs/runs/steer-or-stop-a-run#send-work-back-to-a-station).

To start tasks waiting in the backlog, select **Backlog** and tick the tasks
(the box appears when you point at a row). Select **Move to `<Station>`** in the
bar at the bottom of the board, which names the line's first work station. With tasks ticked at work stations, the same bar offers
**Move to Backlog**.

To change the order of tasks, drag a row up or down within its station.

To close a task, open it and pick **Completed** from the control at the top of
**Properties**, which shows where the task is now and lists only the
stations it may move to. The **Properties** column shows only when the window
is wide enough.

If you move an unassigned task from the backlog to a work station, it becomes
yours.

A run still working at the old station is stopped, one waiting for an answer
is ended, and one still queued is cancelled. [Steer or stop a run](/docs/runs/steer-or-stop-a-run)
covers stopping a run without moving the task.

## Delete a task

Open the task, select **Task options** (the **…** at the top right), then
**Delete task**. Confirm with **Delete task** in the dialog, or keep it with
**Keep it**. Deleting removes everything the stations noted on the task and
stops any run working on it. It cannot be undone.
