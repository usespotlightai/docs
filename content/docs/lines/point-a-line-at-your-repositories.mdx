The built-in Delivery and Review lines start with no repositories. Before you
add some, you need:

- The GitHub App installed on the repositories. If it isn't,
  [connect GitHub](/docs/integrations/connect-github) first.
- The line in Terraform. If your factory isn't in Terraform yet,
  [make the factory yours](/docs/getting-started/make-the-factory-yours) first.

## Add the repositories

Add a `repository` block to the line's `spotlight_line` resource for each
repository, named `owner/name`:

```hcl
resource "spotlight_line" "core_delivery" {
  team_id = spotlight_team.core.id
  key     = "delivery"
  name    = "Delivery"
  role    = "delivery"

  repository {
    name  = "acme/api"
    setup = "go mod download"
  }

  repository {
    name  = "acme/web"
    setup = "npm ci"
  }

  # station blocks as before
}
```

`setup` is a single command that runs in the checkout before each run, such as
one that installs dependencies. To use tools the default runner image lacks,
also set `image`, as in
[Run a line in your own runner image](/docs/hosts/run-a-line-in-your-own-image).
The repositories of a line name at most one image between them.

Run `terraform apply`.

## Check the line

Open the line's board and click the name of a work station. On the Station
page, **Ships through** reads **line · 1 repository**, or **line · 2
repositories** for two, with a pill for each repository. Before, it read
**line · 0 repositories**.
