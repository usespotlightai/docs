Spotlight serves a POSIX shell script at `/api/install.sh` on the Spotlight
address. It needs no sign-in. It installs the `spotlight` binary, then runs
[`spotlight host init`](/docs/reference/cli/spotlight-command#spotlight-host-init)
with the arguments it was given. See [Install a host](/docs/hosts/run-a-host).
On a [self-hosted Spotlight](/docs/reference/glossary#spotlight-address), use
your deployment's address in place of `app.usespotlight.ai`.

```bash
curl -fsSL https://app.usespotlight.ai/api/install.sh | sh -s -- --token <pool token>
```

```bash
curl -fsSL https://app.usespotlight.ai/api/install.sh \
  | sh -s -- --trust <trust id> --oidc-token-file <token file>
```

## Arguments

Every argument after `sh -s --` goes to `spotlight host init`, after
`--url <spotlight address>`. The Spotlight address is the public address of the
Spotlight that served the script, its
[`SPOTLIGHT_PUBLIC_URL`](/docs/reference/self-hosted-settings#addresses-and-sign-in).
A `--url` argument replaces it. See
[spotlight host init](/docs/reference/cli/spotlight-command#spotlight-host-init)
for the flags.

## Variables

These variables control the download only. The host settings come from the
arguments.

| Variable | Default | Description |
| --- | --- | --- |
| `SPOTLIGHT_VERSION` | none | What to install: `latest`, `canary` or a release, as in `v0.1.0`. The script stops on any other value. Without it, the release of the Spotlight that served the script, its [`SPOTLIGHT_RELEASE`](/docs/reference/self-hosted-settings#service), when that is a release, else `canary`, the latest staging build. |
| `SPOTLIGHT_REPO` | `usespotlightai/spotlight` | The GitHub repository releases are downloaded from. |
| `SPOTLIGHT_DOWNLOAD_URL` | none | A base URL to download the binary and checksum from, in place of GitHub releases. |
| `SPOTLIGHT_BIN_DIR` | `/usr/local/bin` as root or when writable, else `~/.spotlight/bin` | Where `spotlight` is installed. |
| `NO_COLOR` | none | Any value prints without color. |

The binary is downloaded from:

| `SPOTLIGHT_VERSION` | URL |
| --- | --- |
| `latest` | `https://github.com/<repo>/releases/latest/download/spotlight-<os>-<arch>` |
| `canary` | `https://github.com/<repo>/releases/download/canary/spotlight-<os>-<arch>`, the newest staging build. It is not a release. |
| a release, as in `v0.1.0` | `https://github.com/<repo>/releases/download/<version>/spotlight-<os>-<arch>` |

`<os>` is `linux` or `darwin`. `<arch>` is `amd64` or `arm64`. The checksum is
the same URL with `.sha256` appended.

## Steps

The script stops at the first failure. Each failure listed under
[Messages](#messages) exits `1`.

| Step | Action |
| --- | --- |
| 1 | Finds `curl` or `wget`, and `sha256sum` or `shasum`. |
| 2 | Reads the platform from `uname -s` and `uname -m`. |
| 3 | Chooses and creates the binary directory. |
| 4 | Finds a container runtime: the first of `docker` or `podman` whose `info` succeeds. |
| 5 | Downloads `spotlight` and its checksum, checks the checksum, and installs the binary at `<bin dir>/spotlight`. |
| 6 | Runs `<bin dir>/spotlight host init --url <spotlight address>` with the script's arguments. `init` asks its questions on the terminal, so they work when the script comes from a pipe. |
| 7 | When `<bin dir>` is not on `PATH`, prints the line to add it. |

The script exits with the exit code of `spotlight host init`.

## Messages

Each failure prints `Sorry, the install stopped:` and the message to standard
error.

| Message | Cause |
| --- | --- |
| `SPOTLIGHT_VERSION is <value>. Set it to latest, canary or a release, as in v0.1.0.` | Any other value. |
| `need curl or wget to download spotlight` | Neither is on `PATH`. |
| `need sha256sum or shasum to check what it downloads` | Neither is on `PATH`. |
| `unsupported operating system: <os>` | Not Linux or macOS. |
| `unsupported architecture: <arch>` | Not x86-64 or ARM64. |
| `no container runtime answered: install and start Docker or Podman (on macOS, Docker Desktop, OrbStack or Colima), then run this again` | No runtime answered `info`. |
| `could not download spotlight from <url>` | The binary download failed. |
| `could not download the checksum from <url>.sha256` | The checksum download failed. |
| `spotlight failed its checksum: expected <sha256>, got <sha256>` | The download does not match its checksum. |

See [spotlight host init](/docs/reference/cli/spotlight-command#spotlight-host-init)
for what `init` prints.
