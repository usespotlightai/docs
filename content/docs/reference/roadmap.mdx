## In review

| Area | What changes |
| --- | --- |
| [Integrations](/docs/reference/terraform/integration) | MCP servers are called from Spotlight itself, so their calls get the same approvals, hooks and journal entries as other tools. |
| [Integrations](/docs/reference/terraform/integration) | Agents can search their tools and read what each one does. |
| [Integrations](/docs/reference/terraform/integration) | Each person can connect their own account to an integration, and OAuth recovers when a provider does not accept a token. |
| [Integrations](/docs/reference/terraform/integration) | Secrets can be sent in query parameters, tools learn the shape of what they return, and a person's policy can override the team's. |

## Planned

| Area | What changes |
| --- | --- |
| App | The Integrations page says what each tool does and whether the team requires approval for it. |
| [Runs](/docs/reference/hosts/sandbox) | Every run is briefed with its environment. |
| [GitHub](/docs/reference/terraform/integration) | A workspace can bring its own GitHub App. |
| [Insights](/docs/reference/app/insights) | Runs and their scores can be exported to outside observability tools through OpenTelemetry. |
| [Memory](/docs/reference/glossary#memory) | A benchmark of team memory, built from Spotlight's own runs. |
