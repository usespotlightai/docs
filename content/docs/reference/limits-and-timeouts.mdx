Values set by configuration show their default and name the setting. Field
lengths and formats are on each resource's own page.

## Runs

See [Runs](/docs/reference/app/tasks-runs-and-the-inbox#runs).

| Item | Value |
| --- | --- |
| Run lease | 60 seconds |
| Lease renewal by the runner | every 2 seconds |
| Lease renewal by the host while a sandbox starts | every 20 seconds |
| Attempts when the runner is lost | 3 in all |
| Attempts while hooks go unanswered | 6 in all, 5 seconds to 2 minutes apart |
| Run wall clock on a host | `SPOTLIGHT_RUN_TIMEOUT`, default 6 hours |
| Stop grace after the wall clock | 30 seconds |
| Messages a person sends, checked for | every 2 seconds |

## Hosts

See [Host settings](/docs/reference/hosts/host-configuration).

| Item | Value |
| --- | --- |
| Presence report | every 20 seconds |
| Shown as answering | a report within the last 90 seconds |
| Remembered after the last report | 24 hours |
| Requirements refresh | every minute |
| Claim long poll | 10 seconds |
| Retry after a failed report or claim | about 2 seconds, doubling to about 30 seconds |
| Sandboxes at once | `SPOTLIGHT_CAPACITY`, default 1 |

## Pools

See [`spotlight_runner_pool`](/docs/reference/terraform/runner-pool).

| Item | Value |
| --- | --- |
| Push pool provision call timeout | 10 seconds |
| Provision attempts | 5 in all, 5 seconds to 2 minutes apart |
| Time for a provisioned runner to claim | 5 minutes |
| Time a provisioned runner waits for its work | 5 minutes |
| `maxRuns` | 1 to 10,000, or no limit |
