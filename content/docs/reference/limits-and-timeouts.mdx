## Workspace archives

See [Inside a sandbox](/docs/reference/hosts/sandbox#run-phases).

| Item | Value |
| --- | --- |
| Packed size | 2 GiB |
| Unpacked size | 8 GiB |
| Upload or download | 30 minutes |
| Kept after its task finishes, or its chat stops carrying the conversation | 7 days |
| Kept after a newer archive replaces it | 1 hour |
| Kept after its task or chat is deleted | none; removed within a minute, even when a run started from it or a replay set pins it |
| Kept after a run that started from it started | 30 days |
| Kept while a run that started from it is in a replay set | until the run leaves the set, the set is deleted, or its station leaves the line |
| An archive never sealed, kept | 24 hours |

An archive a run started from, or one pinned by a replay set, is kept for that
time even when its task has finished or a newer archive has replaced it.
