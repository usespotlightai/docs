lengths and formats are on each resource's own page.

## Runs

See [Runs](/docs/reference/app/tasks-runs-and-the-inbox#runs).

| Item | Value |
| --- | --- |
| Run lease | 60 seconds |
| Lease renewal by the runner | every 2 seconds |
| Lease renewal by the host while a sandbox starts | every 20 seconds |
| Attempts when the runner is lost | 3 in all |
| Attempts while hooks go unanswered | 6 in all, 5 seconds to 2 minutes apart |
| Run wall clock on a host | `SPOTLIGHT_RUN_TIMEOUT`, default 6 hours; the run fails `timed-out` and is tried again, 3 attempts in all, counted with lost runners |
| Stop grace after the wall clock | 30 seconds |
| Messages a person sends, checked for | every 2 seconds |

## Workspace archives

See [Inside a sandbox](/docs/reference/hosts/sandbox#run-phases).

| Item | Value |
| --- | --- |
| Packed size | 2 GiB |
| Unpacked size | 8 GiB |
| Upload or download | 30 minutes |
| Kept after its task finishes, or its chat stops carrying the conversation | 7 days |
| Kept after a newer archive replaces it | 1 hour |
| Kept after a run that started from it started | 30 days |
| Kept while a run that started from it is in a replay set | until the run leaves the set, the set is deleted, or its station leaves the line |
| An archive never sealed, kept | 24 hours |

An archive a run started from, or one pinned by a replay set, is kept for that
time even when its task has finished or a newer archive has replaced it.

See [Searches](/docs/reference/app/searches).

| Item | Value |
| --- | --- |

| Iterations | 1 to 10 |

| Replay runs of a search queued or running at once | 1 to 10, default 4, apart from the team's 2 |
| Copies of each run in its replays (repeats) | 1 to 5, default 1 |
| Searches of a station under way at once | 1 |
| Ceiling | above 0, at most 1,000, in a three-letter currency |
| Share of the ceiling for the agent's runs | a tenth |

| Hypothesis | 1 to 4,000 characters |
| Iterations left for a stalled search to look into why | at least 2 |

| A cause's evidence | 1 to 4,000 characters |
| A cause's suggestion | at most 4,000 characters |
| Points in a search's notice | at most 20, of at most 1,000 characters each |

| An agent run no runner takes | withdrawn after 60 minutes |
