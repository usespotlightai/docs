| Item | Value |
| --- | --- |

## Workspace archives

See [Inside a sandbox](/docs/reference/hosts/sandbox#run-phases).

| Item | Value |
| --- | --- |
| Packed size | 2 GiB |
| Unpacked size | 8 GiB |
| Upload or download | 30 minutes |
| Retained after its task finishes, or its chat stops carrying the conversation | 7 days |
| Retained after a newer archive replaces it | 1 hour |
| Retained after its task or chat is deleted | none; removed within a minute, even when a run started from it or a replay set pins it |
| Retained after a run that started from it started | 30 days |
| Retained while a run that started from it is in a replay set | until the run leaves the set, or its station leaves the line |
| An archive never completed, retained | 24 hours |

An archive a run started from, or one pinned by a replay set, is retained for that
time even when its task has finished or a newer archive has replaced it.
