The web app has keyboard shortcuts on every page in a workspace. Press ? to
see the list in the app. Each command in the list can also be found in the
[search dialog](/docs/reference/app/web-app#search), which shows its keys
beside it.

Keys are given for a Mac. On other systems, Ctrl takes the place of Cmd.

## How keys work

| Rule | Detail |
| --- | --- |
| Sequences | "G then I" means press G, let go, then press I. The second key must come within 1 second of the first. |
| Text fields | A key without Cmd does nothing while the cursor is in a text field, or while a dialog or a menu is open. Cmd+K and Cmd+Enter still work there. |
| Split view | The keys act on the focused pane. |
| Team pages | A key that goes to a team page uses the team of the current page. Outside a team page, it uses the last team visited, or else the first team. |
| Focused item | Some keys act on the item that has keyboard focus. J and K move the focus in a list. |

## General

| Keys | Does |
| --- | --- |
| Cmd+K | Opens or closes the search dialog. |
| / | Opens the search dialog. |
| ? | Shows the keyboard shortcuts. |
| [ | Shows or hides the sidebar. Has no effect on a narrow window. |

## Navigation

| Keys | Goes to |
| --- | --- |
| G then I | The inbox. |
| G then A | The team's Agent page. |
| G then R | The team's Runs page. |
| G then N | The team's Insights page. |
| G then M | The team's Memory page. |
| G then L | The team's line, where the team has one line. Otherwise the search dialog opens on the lines. |
| G then S | The workspace settings. |
| O then L | The search dialog, on the lines. |
| O then S | The search dialog, on the stations. |
| O then T | The search dialog, on the tasks. |

## Lists

These keys work in the inbox list, on a line's board, on the Runs page and in
the trace list of Insights.

| Keys | Does |
| --- | --- |
| J | Moves the focus to the next item. With no item focused, focuses the first. |
| K | Moves the focus to the previous item. With no item focused, focuses the last. |
| Enter | Opens the focused item. |
| X | Selects the focused item, on a board or in the trace list. |
| Esc | Clears the selection, on a board or in the trace list. |

## Tasks

| Keys | Does |
| --- | --- |
| C | Opens a new task at the backlog station of the line, or at its first station where it has no backlog. Outside a line's board, opens the team's first line first. |
| S | On a task page, opens the stations the task can move to, where it can move. On a board with tasks selected, moves them to the station the selection bar names. |
| A | Opens the assignees of the task on its page, or of the focused task on a board. |
| Cmd+Backspace | On a task page, asks to confirm before it deletes the task. |

## Inbox

| Keys | Does |
| --- | --- |
| E | Resolves the focused item, or the open item when no item is focused. On a resolved item that can be reopened, unresolves it. |
| R | Puts the cursor in the reply field of the open item. |
| Cmd+Enter | Approves the approval card that has focus. In the card's edit fields, approves with the changes. |

No key without Cmd approves or dismisses an approval.

## Desktop app

The desktop app adds these keys. The ? list shows them inside the app.

| Keys | Does |
| --- | --- |
| Cmd+T | Opens a new tab. |
| Cmd+W | Closes the tab. |
| Ctrl+Tab or Cmd+Shift+] | Shows the next tab. |
| Ctrl+Shift+Tab or Cmd+Shift+[ | Shows the previous tab. |
| Cmd+1 to Cmd+8 | Shows the tab at that place. |
| Cmd+9 | Shows the last tab. |
| Cmd+[ | Goes back. |
| Cmd+] | Goes forward. |
| Cmd+, | Opens the settings. |
