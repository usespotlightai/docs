title: Get notified about new inbox items
description: Turn on notifications in a browser, so that it tells you when an item comes into your inbox.
---

When you turn on notifications, the browser shows each new item in your
[inbox](/docs/inbox/answer-the-inbox), with its title and the last thing it says.
Select the notification to open the item.
Each browser has its own setting. Turn it on in each browser that you use.

## Turn on notifications

1. Open **Settings**, then **Notifications** under **Account**.
2. Turn on **New inbox items**.
3. When the browser asks, select **Allow**.

The row then reads **On. This browser shows new items, also when Spotlight is
closed.**

If the row reads **On. This browser shows new items while Spotlight is open.**,
this browser or this Spotlight has no Web Push. Keep a Spotlight tab open to
get notifications.

## If the browser blocks notifications

If the row says that the browser blocks notifications, allow notifications for
the Spotlight site in the browser's site settings. Then reload the page and turn
on **New inbox items**.

## Turn off notifications

Turn off **New inbox items** in the same browser. The other browsers that you
use keep their setting.

## What sends a notification

A notification comes for an item that is new or unread in your inbox:

- A station asks you something, or a run of your task fails.
- An inbox request comes in, such as a run to grade or memories to review.
- A notice comes in.

An item that asks again sends a new notification. Items that only show a
running station do not send one.
