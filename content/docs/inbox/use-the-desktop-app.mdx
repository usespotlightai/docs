The desktop app opens Spotlight in its own window. It shows a
[notification](/docs/inbox/get-notified) for each new item in your inbox,
and the number of unread items on its Dock icon. It runs on macOS 12 or later.

## Install the app

1. Open the [latest Spotlight release](https://github.com/usespotlightai/spotlight/releases/latest)
   and download `Spotlight-<version>.dmg`.
2. Open the file and drag **Spotlight** to **Applications**.
3. Open **Spotlight** from **Applications** and log in.

The app updates itself. When an update is ready, macOS shows a notification,
and the app installs the update the next time it quits.

## Keep notifications coming

Closing the window keeps the app running in the Dock, so that notifications
keep coming. To stop them, quit the app with **Spotlight → Quit Spotlight**.

If macOS shows no notifications, open **System Settings → Notifications →
Spotlight** and turn on **Allow notifications**.

## Open Spotlight links in the app

A Spotlight link that you open in a browser, such as one in a GitHub pull
request, can open the same page in the app:

1. In the browser, open **Settings**, then **Notifications** under **Account**.
2. Turn on **Open links in the desktop app**.

The next Spotlight link that you open in that browser goes to the app. The
browser asks once whether it may open Spotlight. Select **Always allow** to
skip the question next time. If the app is not installed, select **Open here
instead** to stay in the browser.

## Use a self-hosted Spotlight

The app opens `https://app.usespotlight.ai`. To open another Spotlight, select
**Spotlight → Spotlight Address…**, enter the address, such as
`https://spotlight.example.com`, and select **Open**. The address must use
`https`.
