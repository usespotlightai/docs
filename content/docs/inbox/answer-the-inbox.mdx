A task assigned to you stops at its station and waits for you when the station
asks you something, when its run fails, or when a tool needs your approval.
Each of these is an item in your inbox. Items that grade a run or report a
station alert sit beside the task and wait on nothing, and so do notices about
your team's work, such as a search you started that stalled.

## Open the item

Open **Inbox** in the workspace sidebar and select an item under **Open**.
Items under **Resolved** are read-only. The right pane shows the conversation:
what the station was asked to do, the steps it took, and what it said last. The row's
preview line and the last note tell you what it is waiting on.

If the row shows `×N`, the same failure has happened N times. Before you
answer again, follow
[Troubleshoot a run](/docs/runs/troubleshoot-a-run).

## Answer the station

Write your reply in the box at the bottom of the item that reads **Reply…**.

- Press Enter to send. Press Shift+Enter for a new line.
- To give the station files, use **Attachments** or drop them on the composer.

The run that asked carries on in the same conversation and reads your answer
as the next thing said to it. If that run failed or was stopped, a new run
starts at the same station and picks up the conversation. The item stays
under **Open** while that run works, and you can follow its steps live in the
same pane.

If the task was opened from Slack, a reply in the thread where its question was
posted answers the item too. See
[Open tasks from Slack and post questions back](/docs/integrations/open-tasks-from-slack).

## Approve, edit or dismiss a request

An approval item says what the agent would like to do, in its own words, above
a card titled **Waiting for your approval**. The card shows the call itself:
the inputs of a tool call, or the command of a harness permission. It comes
from a tool that requires approval or from a harness permission a profile sets
to ask.

- To let the call run as it stands, select **Approve**.
- To change it first, select the pencil icon, change the values in place, and
  select **Approve**. Every input that had a value needs one. Only a tool call
  can be edited; a harness permission is approved or dismissed as it stands.
- To run it yourself instead, select the copy icon.
- To refuse it, select **Dismiss**. If the agent should know why, write it in
  the field that opens, then select **Dismiss** again.

The card then reads "Approved.", "Approved, with changes." or "Dismissed.",
and a new run starts at the same station and picks up the conversation. If you
changed the call, the agent is told what you changed, and the tool runs with
your values. An approval covers one call; the next call asks again. A
dismissal stands: the same call with the same inputs at this station is
refused without asking you.

If Spotlight cannot take your answer, the card says why. See
[Answering an approval](/docs/reference/errors-and-messages#answering-an-approval).

If you write a reply instead of choosing, the run carries on with no decision
and you are asked again when the agent next makes the call.

## Grade a judged run

An item that reads **Grade a judged run, so the team can check its judge.**
asks for your view of one run at a station with a judge. Select **Yes** or
**No**, or a number from 1 to 5. Anyone on the team, or an owner or admin of
the workspace, can grade it, and nothing waits on it. See
[Check a station's judge against people](/docs/improvement/check-a-stations-judge-against-people).

## Look into a station alert

An item that reads **A station crossed one of its alert thresholds.** names the
alert a station's runs crossed and charts its measure run by run. Only people
on the team and the workspace's owners and admins get it. Nothing waits on it.

- To compare the station with the rest of the team, select **See it on
  Insights**.
- To ask the agent for a change to the station, select **Improve this station**
  and follow [Improve a station from its runs](/docs/improvement/improve-a-station-from-its-runs).

The item resolves itself once the station has stayed back within the alert
for as many runs as the alert compares, and opens again if the station crosses
it soon after. See
[Station alerts](/docs/reference/app/tasks-runs-and-the-inbox#station-alerts).

## Act on a notice

A notice has a lightbulb beside its headline. Open it, read the points under
**Details**, and select the button under them to open the page it is about.
For a search that stalled, follow
[If the search stalls](/docs/improvement/search-for-a-better-station-config#if-the-search-stalls).
Once you have dealt with it, select **Dismiss**. It moves under **Resolved**
and leaves the inbox 30 days later.

## Send the task somewhere else instead

If another station should take the work, say so in your answer, and the agent
passes the task on. To stop work on the task or close it, move it to
**Backlog** or **Completed**, as in
[Add a task and move it along a line](/docs/tasks/add-and-move-tasks#move-the-task).
The item then closes with "This moved on to `<Station>`. There is nothing left
to answer."
