title: Find a station to improve
description: Use the team's Insights page to find the station whose runs got worse or trail the rest of the team, and see why.
---

Use this when you want to know which of the team's stations to work on first.
Only people on the team and the workspace's owners and admins can see the
team's Insights.

<Steps>
<Step>

In the sidebar, open the team and select **Insights**. Choose **Past 7 days**,
**Past 30 days** or **Past 90 days** in the period picker.

</Step>
<Step>

On **Overview**, find **Stations worth improving** and start with the first
station: it is worse on the most signals. Expand its row to see which signals
got worse, such as **Sent back** or **Cost per run**. If the card reads
**No station needs attention this period.**, choose a longer period.

</Step>
<Step>

Select the station's runs count to see those runs on the **Runs** tab. Narrow
them with **Outcome**, and select an outcome to open a run.

</Step>
<Step>

To see where the station's runs fail, open **Stations**, select the
station's name under **By station**, and read **Why runs failed**. To see
where its tasks wait, open **Productivity** and read **Where work waits**.

</Step>
<Step>

When you know what to change, select **Improve** on the station's row of
**Stations worth improving**, and follow
[Improve a station from its runs](/docs/improvement/improve-a-station-from-its-runs).

</Step>
</Steps>

To see the runs on a new config, hover over the diamond under its day in
**Output against cost** and select **Runs with config**. To set them against
the runs before, select **Impact** instead.

If changes to the station were already replayed on its past tasks, open
**Stations** and read **Candidates** to see whether any did better than the
live config. See
[Compare the station's candidates](/docs/improvement/replay-past-tasks-against-a-station-change#compare-the-stations-candidates).
